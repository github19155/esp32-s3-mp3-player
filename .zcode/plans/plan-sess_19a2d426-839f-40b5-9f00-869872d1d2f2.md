## 可扩展架构 — ESP32-S3 MP3 播放器

### 架构五大扩展机制

1. **页面注册机制** — 每个页面自描述注册，加新页面不改核心
2. **事件总线** — FreeRTOS 队列，UI 和 BLE 走同一条通道
3. **播放器纯逻辑** — 零 UI 依赖，BLE 遥控直接调 API
4. **配置驱动主菜单** — 静态数组驱动图标网格，改一个 `.enabled` 即激活
5. **链式初始化** — 增删模块只加/减一行 `xxx_init()` / `xxx_register()`

### 开发顺序（9 步）

1. 复制 14-handheld BSP 驱动（完整版：含摄像头/IMU/WiFi 函数）
2. `event/app_event.c` — 事件队列
3. `storage/sd_manager.c` — SD 卡挂载 + opendir/readdir 扫描 MP3
4. `player/player_core.c` — 封装 esp-audio-player，纯逻辑
5. `pages/page_manager.c` — 页面注册表 + 生命周期 + 事件分发
6. `pages/page_main_menu.c` — 配置驱动图标网格（6 图标，仅 MP3 激活）
7. `pages/page_mp3.c` — MP3 播放 UI（列表+播放/暂停/切歌+音量）
8. `main/main.c` — 链式初始化入口
9. 更新 `main/CMakeLists.txt`

### 关键设计决策
- BSP 用 14-handheld 完整版（一次性包含所有外设驱动）
- SD 卡做数据源，POSIX opendir/readdir 替代 file_iterator
- LVGL buff_spiram=true, buff_dma=false（已在 sdkconfig）
- 无开机动画/开机音乐，直接进主菜单
- 页面 overlay 模式（main_obj 底层 + icon_in_obj 上层）
